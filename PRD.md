# Product Requirement Document (PRD)

## Product Name
Accountant

## Version
V1 (Personal MVP)

## Overview

A mobile app to track personal finances using a simple transaction ledger and bill reminder system.

## Target User

Single user managing personal finances manually.

## Core Features (MVP)

- Accounts
- Transactions
- Bills
- Dashboard
- Local storage

## Non-Goals

- Bank sync
- AI features
- Multi-device sync
- Complex analytics

## Success Criteria

User can:
- trust balance
- log transactions quickly
- see upcoming bills clearly
